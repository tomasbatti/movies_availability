# Movies Availability
Repo created to search your letterbox watchlist availability on platforms

## How it works

1. It launches a search on your personal letterbox watchlist
2. For each movie of the watchlist it visit the webpage https://www.buscala.tv/ 
3. For each movie that is available in the platforms it will impact in a database and save it.
4. A dashboard would execute to search each movie on the database and the available platform that its streaming it.
